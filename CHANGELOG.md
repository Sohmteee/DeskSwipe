# Changelog

All notable changes to DeskSwipe will be documented in this file.

## v0.2.1

### Added
- WinUI 3 Settings application
- Configurable swipe direction
- Configurable edge behavior
- Soft, Balanced, and Firm bounce strengths
- Configurable edge feedback messages
- Start with Windows
- Optional Settings window at sign-in
- System tray controls
- Desktop shortcut
- Start Menu shortcuts
- Windows installer

### Fixed
- Fixed gesture runtime startup from the Settings application
- Fixed unreliable compiled gesture runtime output
- Fixed missing tray icon after installation
- Fixed inactive swipe gestures after installation

## v0.2.0

- Initial configurable DeskSwipe release
