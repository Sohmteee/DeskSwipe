# Contributing to DeskSwipe

Contributions are welcome.

## Before contributing

- Check existing issues before opening a new one.
- For bugs, include your Windows version, touchpad model, driver information, and reproduction steps.
- For gesture compatibility issues, include any detected scan codes or relevant input information.

## Development

- Use Windows 10 or Windows 11 x64.
- Install the .NET 8 SDK.
- Install AutoHotkey v2 and Ahk2Exe.
- Install Inno Setup 6 if working on the installer.
- Run .\build.ps1 from the repository root.

## Pull requests

- Keep changes focused.
- Explain what changed and why.
- Test gesture switching, Settings, tray behavior, and startup behavior when relevant.
- Do not commit generated release files.
